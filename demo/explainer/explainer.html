Input

Unstructured data, in a structured request.

Raw state: accessibility snapshot
- heading "Your cart" [level=1] - listitem: Apple × 2: €5.00 - listitem: Pear × 1: €2.00 - status "Order total": Total: €5.00 - textbox "Promo code" - button "Apply" - button "Go to checkout"
Could equally be a stack trace, a diff, a log, or any JSON. JEV reads it as-is.
// POST /v1/systemone
{
"model": "jev-latest",
"state": {
"claim": "The cart total is €7.00",
"accessibility_snapshot": "- heading \"Your cart\" …"
},
"questions": {
"satisfied": {
"type": "noul",
"instructions": "Does the snapshot show the claim is true?",
"criteria": {
"true": "The snapshot clearly shows the claim holds",
"false": "It contradicts the claim or lacks evidence"
}
}
}
}
state: any text or JSON
questions: keyed by id, many per call
type: noul · choice · score
Question types

Three shapes of question. Every answer has a probability.

noul
Is this proposition true?
criteria
"true": "claim holds" "false": "contradicted or no evidence"
answer
{ "type": "noul", "noul": 0.03 }
true
0.03
The probability the claim is true. Here the total is wrong, so the assertion fails: a real bug.
choice
Which one of your options?
criteria
"e12": "button Go to checkout" "e9": "button Apply" "none": "control was removed"
answer
{ "choice": "e12", "probabilities": { "e12": 0.94, … } }
e12
0.94
e9
0.04
none
0.02
A distribution over your keys. It can only pick an option you offered, never an invented one.
score
Where on your ordered scale?
criteria (ordered)
["Unrelated", "Possibly related", "Likely affected", "Directly affected"]
answer
{ "score": 3, "confidence": 0.80 }
Unrelated
0.02
Possibly
0.05
Likely
0.13
Directly
0.80
A level index plus confidence. Good for ranking: severity, relevance, which specs to run first.
Probabilities in this scene are example values. Confidence is a signal to threshold on, not a guarantee.
Output

Typed data. Your code sets the threshold.

const response = await provider.decide({ state, questions })
const p = noulAnswer(response, "satisfied").noul // 0.03
if (p >= config.assertions.threshold) pass() // 0.9
else fail("Claim not supported by the page")
// The response shape is validated at runtime before use.
// A failed call falls back to plain Playwright behaviour.
