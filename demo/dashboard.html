Both lanes run the same 10 tests on the same shop release, one browser each, at the same time. Only the engine answering the questions differs.

We replaced the LLM calls in our tests with JEV.

AI-assisted Playwright suites ask small questions while they run: which button is this now, does this page look right, why did this test fail. Usually a general LLM answers each one. JEV is a fast decision engine built for exactly these questions.

LLM call

A general language model reads the page and writes its answer out as text. Built for conversation and open-ended work.

JEV decision

A decision model reads the page and returns a typed answer with a probability: which element, yes or no, which cause.

0.3 s per question, measured
